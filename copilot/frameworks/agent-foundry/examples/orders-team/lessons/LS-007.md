# LS-007: Money is integer cents

## Statement
The Orders team keeps amounts as integer cents everywhere inside its code and converts only at the border to another system.

## Evidence
- PR #498: the agent flagged a float multiplication; the reviewer accepted and fixed it.
- PR #503: a reviewer asked for cents by hand, with the same intent.
- PR #509: the author agreed ("we always use cents") and fixed the float.

## Rejected alternative
Using a decimal type inside the domain. Rejected because the payment provider already speaks cents and a second representation adds conversions.
