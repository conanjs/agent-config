# agent-config: rules for working in this repo

These apply only when working in this repository. The global instructions every agent loads are `home/instructions/core.instructions.md`.

- **Skills (`plugin/skills/<name>/SKILL.md`):** one file for every coding agent (portable frontmatter: `name`, `description`), shipped as the `agent-config` plugin; `.claude-plugin/marketplace.json` (Claude Code, Copilot CLI) and `.agents/plugins/marketplace.json` (Codex) list it. Paths in a skill are written out (`~/.copilot/...`), never a placeholder. After an edit, run `codex plugin add agent-config@agent-config` so Codex refreshes its copy.
- **Agents (`agents/<name>/`):** `body.md` is the text every coding agent gets; each coding agent that gets it has its own header file in its own keys (`claude.yaml`, `copilot.yaml`, `codex.toml`), no shared header. `adapters/<agent>/adapter.yaml` lists the checked keys. `node scripts/build.mjs` must pass.
- **Patterns (`home/patterns/`):** a new pattern file follows `home/patterns/pattern.schema.md`.
- **Before committing** any change under `home/procedures/`, and always for text drafted in another AI chat: use the `review-docs` skill (`home/procedures/review-docs.procedure.md`), validators first, then the checks they cannot do.
- **Installers** (`installers/install.sh`, `.ps1`, `uninstall.*`): backups land at `~/.agent-config-backups/<timestamp>/` (`%USERPROFILE%\.agent-config-backups\<timestamp>\` on Windows). `SETUP.md` and the README's Usage section describe the mechanism; `home/patterns/backup-before-overwrite.pattern.md` is the general technique.
- **Measuring agent behavior or token cost** (instruction wordings, loading designs, benchmarks): run the tests only on Codex CLI or Copilot CLI with a cheap model, for example `codex exec -m gpt-6-luna` or `copilot --model gpt-5.4-mini`. Do not use Claude Code, or Opus, Sonnet or `gpt-6.1-sol`, unless V asks: these runs spend V's own subscription limits and AI credits. Name the agent and model in every recorded finding, and note that a cheap model may behave differently from the models V uses daily. The method is in `proposals/instruction-loading.md` section 6; record wording results in agent-knowledge `knowledge/ai-agents/instruction-wording-findings.md`.
- **Checks:** `scripts/check-docs.sh` runs this repo's checks and test suites (the knowledge base, company KBs and agentic-sdlc have their own); run it before committing.
