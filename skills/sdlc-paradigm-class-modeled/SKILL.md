Read and apply, in this order:
1. `~/.copilot/frameworks/agentic-sdlc/paradigms/class-modeled.md`
2. `~/.copilot/frameworks/agentic-sdlc/stacks/<stack>/paradigms/class-modeled.md` (stack = the task's `profiles.stack`; if that overlay does not exist, apply step 1 alone and say so in your reply)

(On Windows `~/.copilot` is `%USERPROFILE%\.copilot`.)
The paradigm says how to MODEL the domain; the stack overlay says how that looks in the language and which rules lint/typecheck enforce.
