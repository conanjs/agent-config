# `component/v1`: the manifest every component publishes

**File:** `component.yaml` at a component's root · **Owner:** agent-config · **Consumers:** installer, build, atlas, doctor, renderer, `build cite` · **Record:** DR-402 (with security M-03, M-07, M-08, M-18) · **Spec:** FR-004, FR-005, FR-017, FR-021 to FR-025, AC-1.2, AC-4.5, AC-5.9, AC-9.7, AC-12.7

## Example (agentic-sdlc; comments are normative)

```yaml
schema: component/v1
name: agentic-sdlc                       # ^[a-z0-9][a-z0-9-]{0,63}$, unique across both lists (M-03)
version: 1.4.0                           # the component's own semver; CHANGELOG.md records it
slot: framework                          # one slot from slots/v1
repository: https://github.com/conanjs/agentic-sdlc   # required when provides.exports is not empty (AC-9.7); GitHub only (A-23); no user-info (M-07)
scope: per-project                       # global | per-project; may narrow the slot's scope, never widen it
contracts:
  pin: 1                                 # major of the motherboard contracts this file is written against
locations:                               # every required location of the slot → a folder relative to this file (A-4)
  framework: .                           # relative; no "..", drive letter, "\" or NUL (M-03)
provides:
  contracts: [framework/v1]              # N and N-1 may both appear during a migration
  index: index.md
  exports: []                            # location paths others may cite; removing or renaming one = major version
  skills: skills/                        # skill-source/v1 folders (optional)
  agents: agents/                        # agent-source/v1 folders (optional)
  services: []                           # e.g. { kind: mcp, name: kb-search, command: node, args: [...] } (AC-12.7); privileged (M-01)
depends:
  slots:
    - slot: knowledge-storage
      contract: knowledge-provider/v1
      required: true                     # false = optional; an empty optional slot gives a doctor note, not a NEEDS stop
      docs: []                           # GENERATED by `build cite --write`; a hand edit that differs fails (FR-017)
      suggest:                           # shown in NEEDS as "suggested by agentic-sdlc, unverified"; never fetched without `add` (AC-4.5, M-11)
        source: { type: git, url: https://github.com/conanjs/agent-knowledge.git, ref: main }
    - slot: core
      contract: component/v1
      docs: []                           # generated, e.g. atlas/schemas/atlas.schema.md
    - slot: company-knowledge-storage
      contract: company-kb/v1
      required: false
  runtime:
    node: ">=24.12"                      # checked before apply (AC-5.9); the installer adds git >=2.50.1 for git sources (M-05)
routes:                                  # routes/v1 entries; privileged
  - id: agentic-sdlc
    when: "The project has a .specify/ folder, or the user asks to run the agentic SDLC"
    read: frameworks/agentic-sdlc/index.md
hooks: []                                # hooks/v1 entries; privileged
variables:                               # variables/v1 declarations: public values loaded by agents, never secrets (M-08)
  - name: REFERENCE_REPOS_ROOT
    description: Folder holding reference repositories cloned for comparison
    required: false
idle-cost:                               # ceiling in characters of always-loaded text per agent (G10)
  claude-code: 3500
  copilot-cli: 3200
  codex: 0
```

agent-config's own manifest (`component.yaml` at its root) uses `slot: core`, maps all eight core locations, declares `AGENT_HOME` (computed by the installer, never stored), `AGENT_CONFIG_REPO` and `LANGUAGE`, and exports the core docs other components cite today (for example `atlas/schemas/atlas.schema.md`, `patterns/maintained-variant.pattern.md`, `procedures/procedure.schema.md`, `global-variables.md`); the full list comes from `build cite`, not by hand.

## Rules

| Id | Rule |
|---|---|
| CM-1 | Unknown keys warn and are ignored (CON-10); an unsupported slot or contract major skips only this component (FR-005) |
| CM-2 | `name`, and every skill, agent, route and hook id, match `^[a-z0-9][a-z0-9-]{0,63}$` (M-03) |
| CM-3 | Every path field is relative, has no `..` segment, drive letter, `\` or NUL; at use, its real path must stay under the component root (M-03, M-04) |
| CM-4 | `repository` is required when `provides.exports` is not empty; a GitHub URL with no user-info part (AC-9.7, A-23, M-07) |
| CM-5 | `depends.slots[].docs` equals what `build cite` generates from the component's citations (FR-017) |
| CM-6 | `depends` names slots and contracts, never a repo; `suggest` is display-only (AC-4.5) |
| CM-7 | `variables[].detect` is declarative: `{ kind: env, name }` or `{ kind: dir-exists, candidates: [...] }`; no command form exists (M-18) |
| CM-8 | `routes`, `hooks`, `provides.services`, and skill and agent text are privileged: a new or changed one needs consent at install (M-01) |
| CM-9 | A component may contribute no settings key outside its hook entries (`permissions`, `env`, `apiKeyHelper`, MCP auto-approval are not expressible) (M-09) |

## Missing or stale

Manifest missing or invalid: the component is skipped, `doctor` fails, core still works. Rollout: phase 0 schema; phase 2 reader; manifests written by core (phase 2), agent-companies (3), agent-knowledge (6; in-repo stand-in from phase 2), agentic-sdlc (7; in-repo stand-in from phase 2).
