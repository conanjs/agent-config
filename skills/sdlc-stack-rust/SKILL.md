Read and apply, in this order:
1. `~/.copilot/frameworks/agentic-sdlc/stacks/rust/index.md` (the slot table; run checks only with its `cmd.*` commands, verbatim)
2. `~/.copilot/frameworks/agentic-sdlc/stacks/rust/idioms.md`
3. `~/.copilot/frameworks/agentic-sdlc/stacks/rust/frameworks/<fw>.md` for each framework named in the task's `profiles.framework`, if that file exists

(On Windows `~/.copilot` is `%USERPROFILE%\.copilot`.)
The role's preset foundations say WHAT good code must do; this stack profile says HOW in this language. A paradigm skill, if named, adds the modeling style.
