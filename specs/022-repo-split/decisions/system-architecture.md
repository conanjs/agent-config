- **Tree path:** CC-Q1 (YES: new. Agents keep loading source files until phase 5, AC-8.6) → v1.0. Done.
- **Criteria:** FR-045, FR-046; AC-16.1 to AC-16.10; A-20 to A-22, A-24, A-27; the reliability rules Q-REL-4 (degrade) and DS-2 (time limits).
- **Options considered:** A: whether a component is rendered follows from its citations (any `depends.slots[].docs`, or any own-location path citation in a loaded file); the mounts of a rendered component point at `generated/<component>/`; the session-start re-render has a time limit | B: a `render: true` flag in `component.yaml` | C: render every component, the KB included.
- **Chosen:** A. A flag could disagree with the content.

The default time limit is 5 s, which the plan may tune (QA measures it). A placeholder path such as `companies/<co>/` is not a citation and stays as text (A-24).

## 6. Contract schema sketches for the plan

These sketches are annotated YAML. The plan turns each one into JSON Schema 2020-12 plus the reader checks (tech-stack DR-103). Files that the installer writes are serialized as JSON (tech-stack DR-104) but are shown here as YAML for reading. The comments are normative.

### 6.1 `slots/v1`: `contracts/slots.yaml`

```yaml
schema: slots/v1
slots:
  - name: core
    reserved: true                 # filled only by agent-config's own component.yaml; a list entry naming it is an error
    contract: component/v1         # core's surface is just its provides.exports
    required: true
    multiple: false
    scope: global
    locations:                     # mounts are relative to {{AGENT_HOME}}; they keep the 445 existing lines resolving (AC-8.5)
      - { name: core,          mount: core }
      - { name: instructions,  mount: instructions }
      - { name: patterns,      mount: patterns }
      - { name: procedures,    mount: procedures }
      - { name: references,    mount: references }
      - { name: atlas,         mount: atlas }
      - { name: tracker,       mount: tracker }
      - { name: agent-foundry, mount: frameworks/agent-foundry }
  - name: knowledge-storage
    contract: knowledge-provider/v1          # a string or a list; a list means the filler offers ALL of them
    required: false
    multiple: false
    scope: global
    self-contained: true                     # fillers cite no other component (DR-404); atlas and `build cite` enforce it
    locations:
      - { name: content,              mount: knowledge, index: provided }          # index.md at its root
      - { name: framework,            mount: frameworks/knowledge }
      - { name: company-kb-framework, mount: frameworks/company-kb, required: false }  # required when the filler offers company-kb/v1
  - name: company-knowledge-storage
    contract: [company-kb/v1, knowledge-provider/v1]
    required: false
    multiple: true
    scope: global
    locations:
      - { name: content, mount: companies, shared: true, index: generated }  # entries such as ots/ are linked one by one; each entry has its own index.md
  - name: framework
    contract: framework/v1
    required: false
    multiple: true
    scope: per-project                       # files live in the home; skills, agents and routes appear only where enabled
    locations:
      - { name: framework, mount: "frameworks/{component}" }
# Reader rules: `count` or `mounts` → error naming `required` + `multiple` / `locations` (AC-1.3).
# Two locations with the same mount across installed components → install fails naming both (DR-416).
# Citation classification: the longest mount that prefixes the location path wins; no match → fail (AC-5.10).
```

### 6.2 `component/v1`: `component.yaml` at a component's root

```yaml
schema: component/v1
name: agentic-sdlc                       # [a-z0-9-], unique across both lists
version: 1.4.0                           # the component's own semver; CHANGELOG.md records it
slot: framework                          # one slot from slots/v1
repository: https://github.com/conanjs/agentic-sdlc   # required when provides.exports is not empty (AC-9.7); GitHub only (A-23)
scope: per-project                       # global | per-project; may narrow the slot's scope, never widen it
contracts:
  pin: 1                                 # major of the motherboard contracts this file is written against
locations:                               # every required location of the slot → a folder relative to this file
  framework: .
provides:
  contracts: [framework/v1]              # majors offered; N and N-1 may both appear during a migration
  index: index.md                        # relative to the slot's content (or only) location
  exports: []                            # location paths others may cite; removing or renaming one = major version
  skills: skills/                        # folders in skill-source/v1 form (optional)
  agents: agents/                        # files in agent-source/v1 form (optional)
  services: []                           # optional, e.g. { kind: mcp, name: kb-search, command: node, args: [...] } (AC-12.7)
depends:
  slots:
    - slot: knowledge-storage
      contract: knowledge-provider/v1
      required: true                     # false = optional; an empty optional slot gives a doctor note, not a NEEDS stop
      docs: []                           # GENERATED by `build cite --write`; a hand edit that differs fails (FR-017)
      suggest:                           # shown in the needs report only; never fetched without `add` (AC-4.5)
        source: { type: git, url: https://github.com/conanjs/agent-knowledge.git, ref: main }
    - slot: core
      contract: component/v1
      docs: []                           # generated, e.g. atlas/schemas/atlas.schema.md
    - slot: company-knowledge-storage
      contract: company-kb/v1
      required: false                    # system-level checks are n/a without it (role file, Standalone use)
  runtime:
    node: ">=18"                         # checked before apply (AC-5.9)
routes:                                  # routes/v1 entries (6.7)
  - id: agentic-sdlc
    when: "The project has a .specify/ folder, or the user asks to run the agentic SDLC"
    read: frameworks/agentic-sdlc/index.md
hooks: []                                # hooks/v1 entries (6.10)
variables:                               # variables/v1 declarations (6.11)
  - name: REFERENCE_REPOS_ROOT
    description: Folder holding reference repositories cloned for comparison
    required: false
idle-cost:                               # ceiling in characters of always-loaded text per agent; the build measures it (G10)
  claude-code: 3500
  copilot-cli: 3200
  codex: 0
```

agent-config's own manifest uses `slot: core`, maps all eight core locations, declares `AGENT_HOME` (computed by the installer), `AGENT_CONFIG_REPO` and `LANGUAGE`, and exports the core docs that other components cite today: `atlas/schemas/atlas.schema.md`, `atlas/index.md`, `patterns/maintained-variant.pattern.md`, `procedures/procedure.schema.md`, `procedures/init-github-governance.procedure.md` and `global-variables.md`. The full list comes from `build cite`, not by hand.

### 6.6 `rendered-copy/v1`: renderer rules
